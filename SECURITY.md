# Security Policy

## Supported Versions

This project is pre-1.0 (`0.1.0`) and does not yet maintain parallel release
branches. Security fixes land on `main` and the latest release only.

| Version | Supported |
|---|---|
| 0.1.x (latest, `main`) | yes |
| older | no |

## Reporting a Vulnerability

Do not open a public GitHub issue for a suspected vulnerability.

Email **niksapa150@gmail.com** with a description of the issue, steps to
reproduce, and its potential impact. Include the commit hash or version you
tested against.

You should receive an acknowledgment within a few days. If the report is
confirmed, a fix will be prepared and a coordinated disclosure timeline agreed
on before any public details are published.
